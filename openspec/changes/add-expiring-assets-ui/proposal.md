## Why

首页主导航中的“临期资产”目前尚未提供独立页面，用户无法进入与原站一致的临期资产筛选界面。当前阶段需要补齐一个选项完整、交互可演示但不接入真实资产数据的静态页面，为后续查询与列表能力预留清晰结构。

## What Changes

- 新增本地 `/expiring-assets` 页面，并让主导航“临期资产”进入该页面且显示当前激活态。
- 页面沿用现有站点头部、稳定尺寸的主导航、“顶部”按钮以及不展示相关页脚的项目约束。
- 正文顶部按参考截图显示定位图标和“当前位置 首页 / 临期资产”面包屑。
- 新增原站风格筛选面板，包含“已选条件”“全部撤销”以及区、镇街、到期期限、资产类别四组完整选项。
- 默认选择按截图设置为：区和镇街选择“不限”，到期期限选择“一年内到期”，资产类别选择“不限”。
- 每组筛选均为本地单选，被选项显示红底白字；非默认选择进入“已选条件”区域，“全部撤销”恢复全部默认值。
- 面板底部显示可点击的“更多选项(关键字)”控件；展开后显示原站风格的关键字输入与确认控件，再次点击可收起。
- 关键字及所有基础筛选只维护本地状态，不触发搜索请求、不修改路由，也不改变下方结果。
- 筛选面板下方始终显示现有“敬请期待 / Coming soon”占位，不展示真实资产列表、数量、排序或分页。
- 页面只使用本地代码与既有资源，不加载原站页面、脚本、图片或数据接口。

## Capabilities

### New Capabilities

- `expiring-assets-ui`: 定义临期资产页面路由、面包屑、四组基础筛选、可展开关键字筛选、全部撤销、固定敬请期待结果区和桌面端视觉约束。

### Modified Capabilities

- 无。

## Impact

- 影响 Vue Router、共享主导航路由配置、临期资产视图、筛选配置和筛选面板组件。
- 可复用现有站点头部、主导航、紧凑筛选选项组、`ComingSoon` 与 `BackToTop`，但临期资产需要独立默认值、到期期限选项和关键字展开状态。
- 需要新增端到端测试，覆盖入口与激活态、完整选项与顺序、默认状态、本地单选、更多选项展开/收起、全部撤销、固定占位、无外部请求及多桌面视口布局。
- 不新增后端 API、资产数据、查询请求、分页、第三方 SDK 或新的运行时依赖。
