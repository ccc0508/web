## Why

首页主导航中的“交易动态”目前仍无响应，用户无法进入原站风格的公告筛选页面。当前阶段需要补齐一个选项完整、视觉贴近参考截图但不接入真实公告数据的交易动态静态页面，为后续数据查询与公告列表接入预留结构。

## What Changes

- 新增本地 `/transaction-dynamics` 页面，并让主导航“交易动态”进入该页面且显示当前激活态。
- 页面沿用现有站点头部、主导航、“顶部”按钮和无相关页脚的项目约束。
- 正文顶部按参考截图显示定位图标和“当前位置　首页 / 结果公示”面包屑。
- 新增原站风格筛选面板，包含“已选条件”、右侧“全部撤销”以及区、镇街、资产类别、交易模式、公告类型五组完整选项。
- 默认状态按截图设置：区、镇街、资产类别、交易模式选择“不限”，公告类型选择“交易公告”。
- 区选项包含禅城区、南海区、顺德区、高明区、三水区；镇街完整覆盖截图所示佛山市镇街清单；资产类别、交易模式和公告类型按截图顺序展示。
- 每组筛选均为本地单选，被选项显示红底白字；非默认选择显示在“已选条件”区域，“全部撤销”恢复所有默认值。
- 筛选操作不改变路由、不请求接口、不筛除其他选项，也不产生真实查询结果。
- 面板底部居中显示“更多选项(成交金额、发布日期、关键字)”及方向箭头；点击后按原站样式展开成交金额、发布日期和关键字附加筛选，再次点击可收起。
- 附加筛选仅维护本地选择或输入状态，可纳入“已选条件”并由“全部撤销”恢复默认，但不请求接口、不改变路由和结果占位。
- 修复共享主导航在切换首页、综合信息、交易动态等路由时的宽度重排问题：激活态只改变颜色、背景和底边效果，不改变字号、字重或普通导航项宽度；后续新增本地页面沿用同一稳定规则。
- 筛选面板下方结果区始终显示现有“敬请期待 / Coming soon”占位，不显示公告列表、数量、排序或分页。
- 页面只使用本地代码与既有资源，不加载原站页面、图片、脚本或数据接口。

## Capabilities

### New Capabilities

- `transaction-dynamics-ui`: 定义交易动态页面路由、面包屑、五组基础筛选、可展开的三组附加筛选、全部撤销、稳定共享主导航、固定敬请期待结果区和桌面端视觉约束。

### Modified Capabilities

- 无。

## Impact

- 影响 Vue Router、共享主导航布局规则、交易动态页面视图、筛选配置与筛选面板组件。
- 可复用现有资产类别配置、站点头部、主导航、`ComingSoon` 和 `BackToTop`，但交易动态筛选需要独立的紧凑排版以匹配截图。
- 需要更新端到端测试，覆盖跨路由导航尺寸稳定性、附加筛选展开/收起、默认状态、本地选择与输入、全部撤销、固定结果占位、无外部请求和多桌面视口布局。
- 不新增后端 API、公告数据、筛选请求、分页、第三方 SDK 或新的运行时依赖。
