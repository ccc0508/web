## Why

首页已经预留“交易大厅”入口，但当前点击没有反应，用户无法进入与原站一致的交易入口界面。现在需要先补齐交易大厅首屏框架，为后续会员、指南和交易业务模块预留稳定入口，同时继续保持第一版仅做界面、不接入真实数据和业务能力的范围。

## What Changes

- 将首页主导航中的“交易大厅”从无响应按钮改为站内页面跳转。
- 新增交易大厅页面，只实现原站的顶部欢迎栏、品牌展示区、专用搜索区和红色二级导航。
- 交易大厅品牌文案使用原站交易端内容：主标题“佛山市农村集体“三资”智慧云平台交易系统”、副标题“佛山市农村产权流转交易管理服务平台”、标语“科技赋能未来乡村、数字赋能乡村振兴”。
- 搜索区改为原站交易大厅的单输入框样式，提示语为“请输入你要查询的信息”，保留“搜索”和“项目地图”按钮；本期均为展示控件，不发起查询或跳转。
- 二级导航依次展示“交易大厅”“会员中心”“免责声明”“服务协议”“交易指南”，其中“交易大厅”为黄色激活态；右侧展示“>> 佛山市农村集体“三资”智慧云平台”并返回首页。
- 二级导航下方保持空白，不实现竞投流程、筛选器、项目列表、登录注册、页脚或其他交易内容。
- 保持首页现有日期与星期展示规则，不恢复农历；除“交易大厅”外，首页其他未接入导航继续无响应。

## Capabilities

### New Capabilities

- `trade-hall-ui`: 定义首页交易大厅入口、交易大厅首屏、展示型搜索控件、二级导航和空白内容区的可见行为。

### Modified Capabilities

- 无。

## Impact

- 影响 Vue Router 路由配置、首页主导航、站点头部复用方式、新交易大厅视图与对应样式。
- 需要扩展 Playwright 端到端测试，覆盖首页入口跳转、交易大厅文案与导航、展示型控件以及下方空白范围。
- 不新增后端接口、数据源、认证、地图 SDK 或第三方运行时依赖；页面不得请求原站资源。
