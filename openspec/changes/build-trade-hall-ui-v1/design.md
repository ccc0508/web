## Context

当前项目是 Vue 3 + Vue Router 的单页应用，只有首页路由。首页头部已经用本地 HTML/CSS 实现欢迎栏、品牌区和搜索区，主导航最后一项“交易大厅”目前与其他未接入项共用无响应处理。原站交易端位于独立路径，但本项目不得运行时引用其图片、脚本或接口；本次核对仅用于确认可见文案、搜索结构和导航样式。

## Goals / Non-Goals

**Goals:**

- 在不破坏首页现有布局的前提下复用品牌首屏的视觉基础。
- 为交易大厅建立可直接访问、可从首页进入、可返回首页的站内路由。
- 使交易大厅的搜索结构和二级导航在桌面端接近原站，同时保持所有未接入能力为本地展示态。
- 通过语义标记和端到端测试把“导航以下必须为空白”变成可回归的边界。

**Non-Goals:**

- 不复制原站竞投流程、交易模式、筛选器、列表、登录注册、会员中心或协议页面。
- 不接入搜索接口、项目地图、后端数据、认证、地图 SDK 或原站静态资源。
- 不改造首页其余业务板块，也不恢复首页农历信息。

## Decisions

### 1. 使用独立站内路由承载交易大厅

新增 `/trade-hall` 命名路由与独立视图，由首页主导航定向进入。相比在首页用条件渲染替换整页内容，独立路由可支持刷新和直接访问，也方便后续逐步增加交易模块；相比跳转原站交易端，它满足本项目本地复刻和不依赖外部资源的约束。

### 2. 参数化现有品牌头部而不是复制整套样式

为现有头部增加首页/交易大厅两种展示配置：欢迎栏和品牌视觉继续共用，标题、副标题、搜索结构与修饰样式按模式切换。交易大厅模式隐藏搜索类型下拉框，使用单输入框和原站提示语，并为更长的交易系统标题设置独立字号。相比复制一个几乎相同的头部组件，这样能减少色值和间距漂移；模式配置保持显式，避免大量零散布尔参数。

### 3. 二级导航使用独立轻量组件

交易大厅二级导航与首页主导航的高度、激活颜色和信息架构不同，单独组件更容易复刻原站。五个业务导航项都用按钮呈现，只有右侧平台项使用站内首页链接；这样既保留可访问语义，也可明确控制本期无响应范围。

### 4. 空白内容区仍保留稳定页面高度

视图在二级导航后渲染一个无业务子节点的空白 `main` 区域，并设置最小高度与中性浅色背景。这样截图中能看见明确的空白下半页，同时测试可断言被排除模块没有出现。不会用“暂无数据”占位，因为用户明确要求此处留空白。

### 5. 所有交互限定为本地路由或无副作用事件

搜索提交、项目地图和四个未实现二级导航项统一阻止默认行为且不更新状态；首页返回项只调用 Vue Router。端到端测试监听原站域名请求，确保实现没有因视觉复刻而引入跨站依赖。

## Risks / Trade-offs

- [共享头部模式可能引起首页视觉回归] → 保留首页模式为默认值，并在现有首页测试之外增加首页标题、搜索类型和交易入口回归断言。
- [交易系统标题更长，在 1366 像素宽度可能换行] → 使用交易大厅专用字号和最大宽度，并对 1366、1440、1920 三档进行截图检查。
- [空白内容区容易被误认为遗漏] → 在规格和测试中明确排除模块清单，并给空白主区域稳定的测试标识。
- [原站使用图片式品牌标识，本项目用 CSS 近似实现存在细节差异] → 延续当前项目本地品牌图形和字体体系，优先保证结构、色彩、字号和相对排版一致，不引用原站资源。

## Migration Plan

1. 扩展头部组件配置并先验证首页默认模式无变化。
2. 新增交易大厅导航、视图和路由，再接通首页入口。
3. 增加端到端测试并执行类型检查、构建和多视口视觉核对。
4. 若出现回归，可回退新增路由与入口处理；首页默认头部模式仍可独立工作。
