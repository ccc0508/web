## Why

首页主导航中的“综合信息”目前没有对应页面，无法承接原站的信息栏目入口。当前阶段需要补齐一个视觉贴近原站、但不接入真实文章与查询能力的综合信息静态页面，为后续数据接入预留稳定界面结构。

## What Changes

- 新增本地 `/comprehensive-info` 综合信息页面，并让首页主导航的“综合信息”进入该页面；其他尚未实现的主导航项继续保持无响应。
- 综合信息页面沿用当前项目的站点头部、主导航和“顶部”按钮，不新增底部“关于我们”或“监督投诉”区域。
- 在正文顶部新增“当前位置　首页 / 综合信息”面包屑，并按原站截图构建左侧内容区与右侧筛选栏的双栏布局。
- 左侧内容区不展示文章、图片、日期、摘要或分页，始终使用项目现有“敬请期待 / Coming soon”占位组件。
- 右侧按固定顺序展示工作动态、通知公告、行业资讯、警示曝光、线索征集、帮扶协作、产业规划、政策法规八个栏目；默认激活“工作动态”，点击后仅更新本地激活样式，左侧占位不变。
- 右侧提供起始时间、截止时间、关键字和“查询”按钮；控件允许输入或选择，但提交后不修改内容、不跳转、不更新地址栏，也不发送查询请求。
- 按原站截图精调栏目按钮、筛选控件、两栏宽度、字体、颜色、边框和间距，并确保常见桌面视口无横向溢出。
- 页面只使用本地代码与既有资源，不接入原站资源、文章数据、搜索接口、统计接口或其他后端服务。

## Capabilities

### New Capabilities

- `comprehensive-info-ui`: 定义综合信息页面的本地路由、面包屑、固定敬请期待内容区、八栏目侧边导航、无副作用筛选表单及桌面端视觉约束。

### Modified Capabilities

- 无。

## Impact

- 影响首页主导航点击行为、Vue Router 路由配置、综合信息页面视图及右侧导航/筛选组件。
- 复用现有 `SiteHeader`、`PrimaryNav`、`ComingSoon` 和 `BackToTop` 组件；需要让主导航能够根据当前路由显示首页或综合信息激活态。
- 需要新增端到端测试，覆盖路由进入、栏目顺序与本地激活、静态筛选、固定占位、无外部请求和多桌面视口布局。
- 不新增后端 API、持久化、文章数据、图片/视频/文件、第三方 SDK 或新的运行时依赖。
